# Sana Autopilot

Chrome-розширення, яке автоматично проходить курси на OpenAI PartnerU (`openai-partneru.sana.ai`): пролистує карточки уроку, відповідає на квізи (одиничний/множинний вибір, "Match the pairs"), виконує письмові Exercise-завдання та проходить фінальний Assessment — все через Claude API.

## Що вміє

- Автоклік по кнопці переходу до наступної карточки (`forward-button`), зі скролом, якщо кнопка заблокована до кінця тексту.
- Розв'язання Knowledge check квізів (одна/кілька правильних відповідей) через Claude.
- Розв'язання завдань "Match the pairs" — клавіатурне перетягування правої колонки у потрібний порядок.
- Генерація тексту для письмових Exercise-завдань і автозавантаження його як PDF у форму курсу.
- Проходження фінального Assessment (Final Exam) — послідовні питання + кнопка "Submit assessment" на останньому.
- Автоперехід на наступний курс після "Course completed".
- Лог останніх дій у popup розширення.

## Встановлення

1. Клонуй або завантажй цей репозиторій на диск.
2. Відкрий у Chrome `chrome://extensions`.
3. Увімкни **Developer mode** (перемикач у правому верхньому куті).
4. Натисни **Load unpacked** і вибери папку `sana-autopilot`.
5. Відкрий popup розширення (іконка в тулбарі) і встав свій **Anthropic API ключ** (`sk-ant-...`).

## Використання

1. Відкрий сторінку курсу на `https://openai-partneru.sana.ai/...` або перейди на `https://openai-partneru.sana.ai/learn`.
2. У popup натисни **Сканувати бібліотеку**, щоб побачити курси в процесі, або просто натисни **Запустити на цій сторінці**, якщо вже перебуваєш на потрібному уроці.
3. Розширення саме пролистуватиме картки, відповідатиме на квізи та рухатиметься далі. Хід дій видно в логу popup.
4. Щоб зупинити — натисни **Зупинити** в popup.

## Важливо

- Після кожного оновлення файлів розширення (перевстановлення/`chrome://extensions` → Reload) **обов'язково перезавантаж (F5) усі відкриті вкладки курсу** — інакше в них лишиться стара версія content-скрипта і в консолі зʼявиться помилка `Extension context invalidated`.
- API ключ зберігається лише локально (`chrome.storage.local`) і нікуди, крім `api.anthropic.com`, не надсилається.
- Assessment/Final Exam — це реальний оцінюваний тест: розширення реально його здає і фіксує результат, тому запускай автопілот на ньому свідомо.

## Структура проєкту

```
sana-autopilot/
  manifest.json    # Manifest V3 конфігурація
  background.js    # service worker: виклики Claude API
  content.js       # інжектиться на сторінку курсу, вся логіка автопілоту
  popup.html
  popup.js          # UI: API ключ, старт/стоп, сканування бібліотеки, лог
```
